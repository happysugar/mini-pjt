# TASK-16 장기 메모리 (LangGraph Store)

- 단계: M5
- 예상 시간: 0.5h (추정)
- 선행 작업: TASK-15
- 관련 개념: #10 장기 메모리
- 관련 리뷰 결정: 없음 (설계 그대로)

## 목표
사용자별 선호·비선호·알레르기를 세션이 바뀌어도 기억해 추천에 반영한다.

## 작업 내용
- [ ] `AsyncSqliteStore`(`data/checkpoints.db`) 연결
- [ ] 네임스페이스 `("users", user_id)`에 선호·비선호·알레르기 저장·조회
- [ ] 시드 사용자 정보를 Store에 초기 적재
- [ ] 대화 중 "나 매운 거 싫어" 같은 발화를 선호로 저장하는 도구 (신원은 런타임 주입)
- [ ] 추천 함수가 Store의 알레르기·비선호를 안전 필터에 사용

## 대상 파일
- `src/memory.py`, `src/tools.py`

## 완료 기준
- 새 `thread_id`로 시작한 다음 세션에서도 저장된 선호가 추천에 반영된다.
- 다른 사용자의 Store 항목은 읽을 수 없다.
