## 목표
프롬프트 인젝션, 다른 가족 데이터 접근, 개인정보 노출을 막는다.

## 작업 내용
- [x] 입력 검사: 정규식·키워드로 먼저 검사("이전 지시 무시", 시스템 프롬프트 요청 등), 의심될 때만 LLM 인젝션 분류
- [x] 레시피 메모·품목명에 숨긴 지시는 데이터로만 취급
- [x] 권한: 다른 사용자의 평가 원문·건강 수치 조회 거절, 집계값만 허용
- [x] 출력 마스킹: 전화번호, 이메일, 주민번호, 다른 가족 건강 수치 (S/N·날짜와 겹치지 않는 정규식)
- [x] 개인정보 저장 요청 거절
