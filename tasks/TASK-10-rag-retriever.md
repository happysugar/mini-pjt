## 목표
레시피와 보관 가이드를 한국어로 잘 찾는 검색 파이프라인을 만든다.

## 작업 내용
- [ ] 문서 청킹: 레시피는 요리 단위, 보관 가이드는 품목·팁 단위, 메타데이터에 출처 파일과 요리명
- [ ] Chroma 벡터 인덱스 (Bedrock 임베딩)
- [ ] kiwipiepy 형태소 + `rank-bm25` BM25 인덱스
- [ ] RRF로 두 결과 결합 (직접 구현, `langchain-community` 미사용)
- [ ] 쿼리 확장: 별칭 표 + LLM으로 2~3개 질의 생성 (예: 소고기 → 한우, 우둔, 차돌)
- [ ] LLM 리랭킹: 상위 후보를 Bedrock 채팅 모델이 관련도로 다시 매겨 상위 k개
- [ ] 인덱스는 서버 시작 때 한 번만 로드. 쿼리 확장·리랭킹은 검색 도구 안에서만 실행
- [ ] 검색 도구 `search_recipes`, `search_docs`가 `contexts`에 출처를 담아 반환
