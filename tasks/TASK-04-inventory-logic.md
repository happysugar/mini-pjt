# TASK-04 재고 결정적 로직과 pytest

- 단계: M1
- 예상 시간: 1.5h (추정)
- 선행 작업: TASK-03
- 관련 개념: #2 ReAct 도구의 본체, #4 도구 다중 (계산기)
- 관련 리뷰 결정: 아키텍처 red flag 5 (차감 함수 하나로 통일)

## 목표
LLM이 계산하지 않도록 재고 관련 규칙을 모두 Python 함수로 만들고 테스트로 고정한다.

## 작업 내용
- [ ] S/N 발번 `YYYY-MM-NNN` (투입일자의 연-월 + 월별 순번), 직접 입력 S/N의 형식·중복 검사
- [ ] 품목명 매칭: 정확 일치 → 별칭 일치. 표에 없는 품목은 첫 등록 단위를 `item_units`에 기록
- [ ] 단위 환산: `kg→g`, `ml→L`, `모·팩·봉·알→개`, 기준 단위가 다르면 개당 평균 무게로 환산, 불가하면 "재고 단위 불일치"
- [ ] 유효기간 기본값: `투입일자 + 권장 보관일수`, 없으면 `null` + `unknown`
- [ ] 상대 날짜 변환 ("어제" → `-1` → 날짜)
- [ ] D-day와 알람: 0~3 `imminent`, 음수 `expired`, 4 이상·미상은 없음
- [ ] 차감 함수 하나 `deduct_fefo()`: 유효기간 빠른 순 차감, 부족분 보고, 0이면 `consumed`, `deductions` 기록(차감 시점 D-day, g 환산)
- [ ] 폐기 회피량 `rescued_g_week()`: D-day 0~3 차감분, 가족 합계, 월요일 시작 주, L=1000g, 개=평균 무게
- [ ] 칼로리 계산: 먹은 인분 × 1인분 kcal
- [ ] `tests/test_tools.py`

## 대상 파일
- `src/tools.py`, `tests/test_tools.py`

## 완료 기준 (pytest, `FRIDGE_TODAY` 고정)
- S/N 형식과 월별 순번, 중복 S/N 거부
- 유효기간 기본값과 미상 처리
- D-day 경계: 3 → imminent, 0 → imminent, -1 → expired, 4 → 없음
- `1모`→`1개`, 기준 단위 불일치, 표에 없는 품목의 첫 등록 단위 고정
- 재고 부족 시 부분 차감과 부족분 보고
- 폐기 회피량 (L, 개, 평균 무게 없는 품목 제외)
