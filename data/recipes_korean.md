# 한식 레시피

## 문서 형식 (파서 규칙)

- 레시피 하나는 `## 요리명`으로 시작하고, 다음 `## ` 제목 전까지입니다.
- 제목 바로 아래 한 문단은 레시피 요약입니다.
- 메타 표: `항목 | 값` 두 열. 행은 `카테고리`, `주재료`, `1인분 kcal`, `알레르기` 네 개입니다. 알레르기가 없으면 `없음`이라고 적습니다.
- `### 재료 (1인분 기준)` 표: `재료 | 인분당 양 | 기준 단위` 세 열. 주재료도 이 표에 들어 있습니다. 재료명과 기준 단위는 `storage_guide.md` 품목 기준표와 같습니다.
- `기본 재료:` 줄은 밥, 양념, 기름처럼 재고로 관리하지 않는 재료입니다. 부족 재료 계산과 재고 차감에서 빠집니다.
- `### 조리 순서`는 번호 목록입니다.

## 소고기 무국

소고기와 무를 참기름에 볶다가 끓여 낸 맑은 국입니다. 국간장으로 간을 해 담백하고 시원합니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 한식 |
| 주재료 | 소고기 |
| 1인분 kcal | 220 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 소고기 | 80 | g |
| 무 | 150 | g |
| 대파 | 0.3 | 개 |

기본 재료: 국간장 1큰술, 다진 마늘 1/2큰술, 참기름 1/2큰술, 소금 약간, 물 400ml

### 조리 순서

1. 소고기는 한입 크기로 썰고 키친타월로 핏물을 닦습니다.
2. 무는 나박썰기하고, 대파는 어슷썰기합니다.
3. 냄비에 참기름을 두르고 소고기를 볶다가 겉면이 익으면 무를 넣어 2분 더 볶습니다.
4. 물을 붓고 센 불로 끓이다가 거품을 걷어 내고, 중불에서 15분 끓입니다.
5. 다진 마늘과 국간장을 넣고, 소금으로 간을 맞춘 뒤 대파를 넣고 1분 더 끓입니다.

## 된장찌개

두부와 애호박, 감자를 된장 국물에 끓인 찌개입니다. 밥과 함께 먹는 가장 흔한 집밥 메뉴입니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 한식 |
| 주재료 | 두부 |
| 1인분 kcal | 180 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 두부 | 0.3 | 개 |
| 애호박 | 0.2 | 개 |
| 감자 | 0.5 | 개 |
| 양파 | 0.25 | 개 |
| 대파 | 0.2 | 개 |

기본 재료: 된장 1.5큰술, 고춧가루 1/2작은술, 다진 마늘 1/2작은술, 멸치 육수 300ml

### 조리 순서

1. 감자, 애호박, 양파, 두부를 깍둑썰기하고 대파는 송송 썹니다.
2. 멸치 육수에 된장을 풀고 감자를 넣어 5분 끓입니다.
3. 애호박과 양파를 넣고 3분 더 끓입니다.
4. 두부, 다진 마늘, 고춧가루를 넣고 2분 끓인 뒤 대파를 올립니다.

## 김치볶음밥

잘 익은 김치를 볶아 밥과 섞고 계란 프라이를 올린 볶음밥입니다. 너무 익은 김치를 쓰기에 좋습니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 한식 |
| 주재료 | 김치 |
| 1인분 kcal | 550 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 김치 | 100 | g |
| 계란 | 1 | 개 |
| 대파 | 0.2 | 개 |

기본 재료: 밥 1공기, 식용유 1큰술, 간장 1/2큰술, 설탕 약간, 참기름 약간

### 조리 순서

1. 김치는 잘게 썰고 대파는 송송 썹니다.
2. 팬에 식용유를 두르고 대파를 볶아 파기름을 냅니다.
3. 김치를 넣고 3분 볶은 뒤 간장과 설탕을 넣습니다.
4. 밥을 넣고 고루 섞어 볶은 뒤 참기름을 두릅니다.
5. 다른 팬에 계란 프라이를 만들어 볶음밥 위에 올립니다.

## 계란말이

계란물에 잘게 썬 채소를 섞어 얇게 부친 뒤 돌돌 말아 낸 반찬입니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 한식 |
| 주재료 | 계란 |
| 1인분 kcal | 200 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 계란 | 2 | 개 |
| 당근 | 0.1 | 개 |
| 대파 | 0.1 | 개 |

기본 재료: 소금 약간, 식용유 1큰술

### 조리 순서

1. 당근과 대파를 아주 잘게 다집니다.
2. 계란을 풀고 다진 채소와 소금을 넣어 섞습니다.
3. 약불로 달군 팬에 기름을 얇게 두르고 계란물의 1/3을 붓습니다.
4. 반쯤 익으면 한쪽 끝부터 말고, 남은 계란물을 나눠 부으며 이어서 맙니다.
5. 한 김 식힌 뒤 도톰하게 썹니다.

## 해물파전

대파를 듬뿍 깔고 새우를 올려 바삭하게 부친 전입니다. 새우가 들어가므로 갑각류 알레르기가 있으면 먹을 수 없습니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 한식 |
| 주재료 | 대파 |
| 1인분 kcal | 450 |
| 알레르기 | 갑각류 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 대파 | 1 | 개 |
| 새우 | 50 | g |
| 계란 | 1 | 개 |

기본 재료: 부침가루 80g, 찬물 100ml, 식용유 3큰술, 초간장 약간

### 조리 순서

1. 대파는 팬 길이에 맞춰 자르고, 새우는 껍질을 벗겨 굵게 다집니다.
2. 부침가루와 찬물을 섞어 반죽을 만듭니다.
3. 달군 팬에 기름을 넉넉히 두르고 대파를 가지런히 깝니다.
4. 반죽을 얇게 붓고 새우를 올린 뒤, 계란을 풀어 위에 끼얹습니다.
5. 밑면이 노릇해지면 뒤집어 3분 더 부치고 초간장을 곁들입니다.

감자와 당근을 간장 양념에 윤기 나게 조린 밑반찬입니다.

| 항목 | 값 |
|---|---|

| 주재료 | 감자 |
| 1인분 kcal | 180 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 감자 | 1 | 개 |
| 양파 | 0.25 | 개 |
| 당근 | 0.2 | 개 |

기본 재료: 간장 1.5큰술, 올리고당 1큰술, 식용유 1큰술, 물 100ml, 통깨 약간

### 조리 순서

3. 팬에 기름을 두르고 감자와 당근을 3분 볶습니다.
4. 물, 간장을 넣고 뚜껑을 덮어 중불에서 10분 조립니다.
5. 양파와 올리고당을 넣고 국물이 거의 없어질 때까지 조린 뒤 통깨를 뿌립니다.

## 시금치나물

데친 시금치를 국간장과 참기름으로 무친 나물입니다. 시금치는 빨리 시드므로 사 온 뒤 바로 만드는 것이 좋습니다.

| 항목 | 값 |
|---|---|

| 주재료 | 시금치 |
| 1인분 kcal | 70 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 시금치 | 100 | g |
| 대파 | 0.1 | 개 |

기본 재료: 국간장 1/2큰술, 다진 마늘 1/3작은술, 참기름 1/2큰술, 통깨 약간, 소금 약간

### 조리 순서

3. 대파를 곱게 다집니다.
4. 시금치에 국간장, 다진 마늘, 대파를 넣고 무친 뒤 참기름과 통깨를 넣습니다.

| 항목 | 값 |
|---|---|

| 주재료 | 두부 |

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|

4. 양념장과 대파를 두부 위에 끼얹고, 약불에서 국물이 자작해질 때까지 5분 조립니다.
