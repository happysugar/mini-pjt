# 중식 레시피

## 문서 형식 (파서 규칙)

- 레시피 하나는 `## 요리명`으로 시작하고, 다음 `## ` 제목 전까지입니다.
- 제목 바로 아래 한 문단은 레시피 요약입니다.
- 메타 표: `항목 | 값` 두 열. 행은 `카테고리`, `주재료`, `1인분 kcal`, `알레르기` 네 개입니다. 알레르기가 없으면 `없음`이라고 적습니다.
- `### 재료 (1인분 기준)` 표: `재료 | 인분당 양 | 기준 단위` 세 열. 주재료도 이 표에 들어 있습니다. 재료명과 기준 단위는 `storage_guide.md` 품목 기준표와 같습니다.
- `기본 재료:` 줄은 밥, 양념, 기름처럼 재고로 관리하지 않는 재료입니다. 부족 재료 계산과 재고 차감에서 빠집니다.
- `### 조리 순서`는 번호 목록입니다.

## 소고기 굴소스볶음

얇게 썬 소고기와 양파, 표고버섯을 센 불에 굴소스로 빠르게 볶은 요리입니다. 밥 위에 얹어 덮밥으로 먹어도 좋습니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 중식 |
| 주재료 | 소고기 |
| 1인분 kcal | 420 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 소고기 | 100 | g |
| 양파 | 0.5 | 개 |
| 표고버섯 | 30 | g |
| 대파 | 0.3 | 개 |

기본 재료: 굴소스 1큰술, 간장 1/2큰술, 다진 마늘 1/2큰술, 전분물 1큰술, 식용유 1큰술, 후추 약간

### 조리 순서

1. 소고기는 결 반대로 얇게 썰어 간장과 후추로 10분 재웁니다.
2. 양파는 굵게 채 썰고, 표고버섯은 얇게 썰고, 대파는 어슷썰기합니다.
3. 달군 팬에 기름을 두르고 다진 마늘과 대파를 볶아 향을 냅니다.
4. 소고기를 넣고 센 불에서 겉면이 익을 때까지 볶은 뒤 양파와 표고버섯을 넣어 1분 더 볶습니다.
5. 굴소스를 넣고 섞은 뒤 전분물로 농도를 맞춥니다.

## 마파두부

두부와 다진 돼지고기를 두반장 소스에 끓인 매콤한 요리입니다. 밥에 얹어 덮밥으로 먹습니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 중식 |
| 주재료 | 두부 |
| 1인분 kcal | 380 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 두부 | 0.5 | 개 |
| 돼지고기 | 50 | g |
| 대파 | 0.3 | 개 |

기본 재료: 두반장 1큰술, 다진 마늘 1/2큰술, 간장 1/2큰술, 설탕 1작은술, 전분물 1큰술, 식용유 1큰술, 물 150ml

### 조리 순서

1. 두부는 사방 2cm로 썰어 끓는 물에 1분 데쳐 건집니다.
2. 대파는 송송 썹니다.
3. 달군 팬에 기름을 두르고 다진 마늘과 대파 절반을 볶다가 돼지고기를 넣어 볶습니다.
4. 두반장, 간장, 설탕, 물을 넣고 끓으면 두부를 넣어 3분 끓입니다.
5. 전분물로 농도를 맞추고 남은 대파를 올립니다.

## 토마토 계란볶음

부드럽게 익힌 계란과 토마토를 함께 볶은 새콤달콤한 가정식 요리입니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 중식 |
| 주재료 | 계란 |
| 1인분 kcal | 260 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 계란 | 2 | 개 |
| 토마토 캔 | 0.25 | 개 |
| 대파 | 0.2 | 개 |

기본 재료: 설탕 1작은술, 소금 약간, 식용유 2큰술

### 조리 순서

1. 계란은 소금을 약간 넣어 풀고, 대파는 송송 썹니다.
2. 달군 팬에 기름을 두르고 계란을 부어 반쯤 익으면 덜어 냅니다.
3. 같은 팬에 대파를 볶아 향을 내고 토마토를 넣어 으깨며 2분 볶습니다.
4. 설탕과 소금으로 간하고 계란을 다시 넣어 가볍게 섞습니다.

## 계란볶음밥

계란과 채소를 센 불에 밥과 함께 볶아 고슬고슬하게 만든 볶음밥입니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 중식 |
| 주재료 | 계란 |
| 1인분 kcal | 520 |
| 알레르기 | 없음 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 계란 | 1 | 개 |
| 양파 | 0.25 | 개 |
| 당근 | 0.2 | 개 |
| 대파 | 0.2 | 개 |

기본 재료: 밥 1공기, 간장 1/2큰술, 소금 약간, 후추 약간, 식용유 2큰술

### 조리 순서

1. 양파와 당근은 잘게 다지고, 대파는 송송 썹니다.
2. 달군 팬에 기름을 두르고 대파를 볶아 파기름을 냅니다.
3. 양파와 당근을 넣어 1분 볶은 뒤 한쪽으로 밀고 계란을 풀어 스크램블합니다.
4. 밥을 넣고 센 불에서 풀어 가며 볶습니다.
5. 팬 가장자리에 간장을 둘러 향을 내고 소금과 후추로 간합니다.

## 깐쇼새우

바삭하게 튀긴 새우를 매콤달콤한 칠리소스에 버무린 요리입니다. 새우가 들어가므로 갑각류 알레르기가 있으면 먹을 수 없습니다.

| 항목 | 값 |
|---|---|
| 카테고리 | 중식 |
| 주재료 | 새우 |
| 1인분 kcal | 450 |
| 알레르기 | 갑각류 |

### 재료 (1인분 기준)

| 재료 | 인분당 양 | 기준 단위 |
|---|---|---|
| 새우 | 120 | g |
| 양파 | 0.25 | 개 |
| 대파 | 0.2 | 개 |

기본 재료: 전분 3큰술, 칠리소스 2큰술, 케첩 1큰술, 설탕 1작은술, 다진 마늘 1/2큰술, 식용유 넉넉히

### 조리 순서

1. 새우는 껍질과 내장을 빼고 물기를 닦은 뒤 전분을 입힙니다.
2. 170도 기름에 새우를 2분 튀겨 건집니다.
3. 양파는 잘게 다지고, 대파는 송송 썹니다.
4. 팬에 기름을 조금 두르고 다진 마늘, 양파, 대파를 볶다가 칠리소스, 케첩, 설탕을 넣어 끓입니다.
5. 튀긴 새우를 넣고 소스에 재빨리 버무립니다.
